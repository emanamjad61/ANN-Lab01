## Lab 01 — Python Fundamentals

Notebook: [`ANN_Lab01.ipynb`](ANN_Lab01.ipynb)

All nine lab tasks (36 parts in total) are solved in a single Jupyter notebook.
Every part sits in its own code cell with its output already saved, so the notebook
can be read straight from GitHub without running it first.

### What each task covers

**Task 1 — Variables and Basic Operators**
Declaring variables, inspecting them with `type()`, the `+=` and `-=` shorthand
operators, comparison operators, and swapping two values through tuple unpacking.

**Task 2 — Working with Lists**
Building a list, growing it with `append()` and `insert()`, shrinking it with
`remove()` and `pop()`, then sorting with `sorted()`.

**Task 3 — Tuples and Dictionaries**
Tuple immutability (including the `TypeError` it raises), and creating, updating
and extending a dictionary of subject credit hours.

**Task 4 — Indexing and Slicing**
Slice ranges, negative indexing, step slicing, and reversing a list with `[::-1]`.

**Task 5 — String Processing**
`split()`, f-string formatting, counting vowels with a loop, and case conversion
with `upper()` and `lower()`.

**Task 6 — Conditional Statements**
Grade calculation with `if`/`elif`/`else`, sign checking, a nested-`if` leap year
test, and combining conditions with `and` / `or`.

**Task 7 — Loops with Break and Continue**
Skipping values with `continue`, exiting early with `break`, a `while` loop
multiplication table, and summing even numbers.

**Task 8 — Functions**
Default parameter values, return values, and a demonstration that lists are passed
by reference rather than copied.

**Task 9 — Classes and Inheritance**
A `Course` class, a `LabCourse` subclass built with `super().__init__()`, and
method overriding.
